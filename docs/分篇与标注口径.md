# 分篇与标注口径

## 这本书怎么来的

素材是一个文件（`人间防骗指南.md`）：原始口播稿合集，加上已合并进去的两轮增补内容（机票退改签、快递理赔、医保ETC短信、演唱会门票、百万保障、培训退费、FaceTime、屏幕共享、征信修复、注销校园贷、被骗自救、反诈工具，以及 2026 最新骗局）。构建脚本 `tools/parse_articles.py` 把它切成 373 篇：

1. **按结尾话题标签行分篇**——每篇稿子最后一行是 `#话题 #话题` 形式的标签，先分块；
2. **按标题行二次补切**——少数篇目漏写标签行，用「标题特征」（emoji 前缀白名单 + 揭秘/骗局/陷阱等强词 + 无冒号 + 长度区间 + 疑似叹号结尾）补切；
3. **按标题去重**——完全相同的重复投稿只留第一篇；原始口播稿 319 篇 + 增补内容 45 篇（第一轮 23 篇 + 第二轮 22 篇 2026 最新骗局）。

## 每篇的标注怎么打

- **骗局类型（16 类）**：关键词加权打分取最高分。词表按特指程度配权重（「刷单」权重高于「兼职」），兜底类「黑灰产大盘」打分打 45 折，避免泛词抢走具体分类。增补的 45 篇由标题【栏目名】直接指定分类（民生骗局/反诈工具箱/冒充来电/征信陷阱，以及第二轮的大盘新变/学生新骗局/AI新骗局/资金新骗局/副业新骗局/帮信新骗局/投资新骗局），不参与打分，避免泛词把旧文误吸进新类。
- **你会损失什么（6 种）**：刑责风险 / 钱财损失 / 账号封禁 / 隐私泄露 / 征信受损 / 人身安全。命中多个风险词累计加分，过阈值才标注。
- **专盯谁（6 类）**：中老年 / 女性 / 学生党 / 商家店主 / 求职者 / 负债人，同样阈值制。
- **要点 / 防身金句**：要点取自正文步骤行（去序号、截到停顿）；防身句限定收尾/建议段落里的「切勿/凡是/千万不要」句式。

## 报道怎么挂

`tools/news.json` 收录公开报道；每篇按「类型默认挂载 + 关键词触发加权」匹配，最多 4 条，关键词命中的（更特指）排前面。

## 局限（务必读）

- 口播稿是叙事文本，不是判例文书；正文数字（金额、刑期）以原稿为准，具体案情以所附报道原文为准。
- 标注是脚本自动打的，为的是检索，不代表个案的法律认定。
- 报道匹配是「同类案例」而非「同一案件」：某篇讲闲鱼调包，挂的是法院/警方公开通报的闲鱼调包类案例。
- 遇到正在进行的事：打 110 报案、96110 咨询，或通过「国家反诈中心」App 举报。
