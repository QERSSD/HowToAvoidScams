# 术语表 · 黑话速查

骗子圈和反诈报道里的黑话，一句话讲清「是什么 + 在骗局链条里的位置 + 对普通人意味着什么」。共 42 条，按性质分四类；每条关联的出现最多文章可直接在离线应用里搜编号查看。同名内容也做成了 Anki 黑话卡（`downloads/人间防骗指南.apkg` 的「黑话速查」牌组）。

## 骗局类型

**杀猪盘**　<sub>常见于：情感 · 色情陷阱 / 投资 · 虚拟币</sub>

网络交友诱导投资的骗局统称。骗子先「养猪」——聊天建立恋爱或知己关系，再「杀猪」——诱导受害者在假平台充值投资，最后卷款消失。书里情感类、投资类骗局多数是它的变体。

**刷单**　<sub>常见于：兼职 · 刷单</sub>

假装网购刷销量返佣金。前几单小额返利建立信任，随后「大单」「连单」要求垫付，钱一垫就回不来。本身也是违法行为，平台和警方都不会给你「垫付任务」。

<sub>关联拆解：#147《曝光！从尝到甜头到连环被套，刷单骗局一次被套走 》、#34《校园调研问卷竟是套利工具？揭秘“问卷刷单”黑灰产》、#322《不明快递里的"蟹卡"和"提货券"，是刷单诈骗的新》</sub>

**垫付**　<sub>常见于：兼职 · 刷单 / 民生 · 缴费票务</sub>

骗局里的关键动作词：让你先用自己的钱付出去，承诺事后返还+佣金。凡是兼职、理赔、退费里出现「先垫付」，就是收网信号。

**搬砖**　<sub>常见于：投资 · 虚拟币</sub>

打着「低买高卖赚差价」旗号的资金盘：虚拟币搬砖、搬砖套利……收益全靠拉新人的钱付老人利息，崩盘只是时间问题。

**带单/喊单**　<sub>常见于：投资 · 虚拟币 / 网赌 · 博彩</sub>

直播或群里「老师」带着你下单：先故意让你赚两笔小钱，再诱导加大投入甚至带进假盘口。老师看得到你的仓位，你看不到他的后台。

**盘口**　<sub>常见于：网赌 · 博彩 / 投资 · 虚拟币</sub>

可以做「涨跌」的假交易平台。前端看着像国际行情，后台数据全是骗子改的——你赢的是数字，输的是真钱，且永远提不了现。

**倍投**　<sub>常见于：网赌 · 博彩</sub>

「输了翻倍下注就回本」的赌徒算法。数学上只要连输几次，需要的本金指数增长，任何钱包都扛不住——赌局唯一稳赚的是庄家。

**上分/下分**　<sub>常见于：网赌 · 博彩</sub>

网赌黑话：往平台充钱叫上分，提现叫下分。骗子控制的平台里，上分秒到账，下分要「交税」「解冻费」「流水不够」——到最后一步也提不出来。

**拉人头**　<sub>常见于：黑灰产大盘 / 求职 · 加盟</sub>

传销的核心动作：收益不靠卖东西，靠发展下线。三级分销、拉人返佣、高额加盟费，本质都是击鼓传花，法律上三级即可构成传销罪。

把受害人反复收割的比喻：一茬又一茬。直播间「家人们」、荐股群「学员们」都是待割的韭菜，庄家出货时跑得比谁都快。

以借贷为名行占有之实：砍头息、虚增债务、转单平账、恶意垒高借款，最后用暴力催收或虚假诉讼逼你交房交车。记住：正规机构不会主动放贷给「急用钱的你」。

远低于面值价充话费/会员的服务，到账慢。资金来源大概率是洗赃款：你的「优惠充值」帮水房过了一道手，充进去的号码也可能被卷进案件。

## 产业链角色

**跑分**　<sub>常见于：洗钱 · 银行卡</sub>

用自己的银行卡或收款码帮骗子转移赃款，按流水抽成。每一笔都发生在你名下的账户里——警方顺资金链查到的第一个名字就是你，涉嫌帮信罪或掩隐罪。

**水房**　<sub>常见于：洗钱 · 银行卡 / 黑灰产大盘</sub>

专门把赃款「洗白」分拆转移的团伙窝点：把钱拆成小额、多卡、多层转账，最后通过虚拟货币、购物卡变现。跑分的人就是水房最外围的手。

<sub>关联拆解：#138《曝光！凭什么我取几万被查户口，骗子转几百万畅通无》</sub>

**卡农**　<sub>常见于：洗钱 · 银行卡</sub>

专门收购、收集银行卡卖给水房的人。一张「四件套」卡能卖几百到上千元，卖卡的人从此对这张卡上的一切资金往来负责。

**狗推**　<sub>常见于：黑灰产大盘 / 求职 · 加盟</sub>

境外诈骗园区里最底层的业务员，在社交软件上冒充「高富善」「客服」「老师」广撒网聊天拉人。工资低、完不成业绩会被打骂，很多人自己也是被「高薪工作」骗过去的。

**四件套**　<sub>常见于：洗钱 · 银行卡</sub>

## 法律名词

**断卡**　<sub>常见于：洗钱 · 银行卡 / 应急 · 反诈工具</sub>

「断卡行动」：国家从 2020 年起对涉诈银行卡、电话卡的专项打击。惩戒名单内的人 5 年内不能开新卡、非柜面业务受限——出租银行卡的代价远不止一顿官司。

**GOIP**　<sub>常见于：冒充 · 公检法 / 黑灰产大盘</sub>
