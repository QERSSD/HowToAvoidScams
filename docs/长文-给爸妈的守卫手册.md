# 给爸妈的防骗守卫手册：从免费鸡蛋到养老项目，一条链子拆到底

> 长文 · 综合自「老人 · 学生 · 宝妈」类 11 篇及民生、投资类相关拆解。写给子女——防骗这件事，你多问一句，爸妈就少亏十万。

针对老人的骗局不是一个一个出现的，是**一条完整的生产线**：每一环都有专人负责。这篇长文把整条链子拆开，然后给你一套能在饭桌上讲完的防守动作。

## 一、生产线：老人的钱是怎么被搬走的

```
第一环 拿信息：快递面单、保健品登记表、免费体检报名表 → 黑市按条卖
第二环 给甜头：免费鸡蛋、免费旅游、免费体检 → 建立「他们对我好」的信任
第三环 造权威：白大褂「专家」、直播间「贴心主播」、「孙老师」 → 替爸妈做判断
第四环 讲故事：保健品能停药、收藏品会翻倍、养老床位高息返租 → 造一个能圆的梦
第五环 收钱：小额试水 → 大额「疗程」「原始股」 → 抵房抵养老钱
第六环 堵退路：「别告诉儿女，他们不懂」 → 隔离最后能拉刹车的人
```

对照真实案件看这条链子：新华网通报的中宁特大直播养老诈骗案，直播间「贴心主播」卖三无保健品，涉案 1000 万、受害人多为老年人、12 人落网（[新华网](http://www.ningxia.xinhua.org/20260713/b716d1a7166444119d04cab9535830a4/c.html)）；郑州反诈中心通报的「老物件高价回收」直播骗局，75 岁老人被「你的粮票值十几万，先交 1.4 万手续费」骗走养老钱（[郑州市政府](https://www.zhengzhou.gov.cn/news1/10292256.jhtml)）——手法不同，链子一模一样。

## 二、六个高发剧本（按上门频率排序）

1. **免费领鸡蛋 → 保健品疗程**。#304 的拆解里这套打法叫「指数级裂变」：领鸡蛋加微信群 → 群里晒「疗效」的托 → 直播间限时抢购「专家配方」。终点是让老人停掉正规药。
2. **收藏品 / 老物件高价回收**。「祖传的旧邮票值 50 万，先交拍卖服务费」。凡是要先交钱才能拿到钱的「好事」，都是剧本。
3. **高息养老项目**。养老床位返租、生态庄园原始股、高息存款——本质全是非法集资，本金归零只是时间问题。
4. **冒充子女 / 孙辈出事**。「爸，我出车祸了，速转手术费」。一条微信语音都可能 AI 合成的今天，**暗号**是唯一靠得住的东西。
5. **冒充公检法「涉案」**。假警官证 + 假通缉令 + 「安全账户」。老人对制服的信任度最高，恰好是这个剧本的靶心（人民网通报的同类案件见[反诈中心案例](https://xj.people.com.cn/n2/2021/0907/c394722-34903500.html)）。
6. **黄昏恋 / 陪伴型杀猪盘**。丧偶老人是杀猪盘的高价值目标：感情建立半年，收割一波带走。子女往往最后一个知道。

## 三、防守动作：饭桌上能讲完的五件事

**第 1 件：装 + 授权。**
给爸妈手机装国家反诈中心 App，开启来电预警，并关掉「陌生来电免打扰」。这是系统级拦截，比任何叮嘱都可靠。

**第 2 件：约暗号。**
和家人约定一个只有自己人知道的问题-答案（「老家院里那棵树是什么树？」）。凡是「家人出事要钱」「朋友代家人开口」，先对暗号。一句话，拆掉剧本 4。

**第 3 件：立规矩——三不碰。**
- 别人**送上门**的「高息」不碰（养老项目、原始股）；
- 要**先交钱**才能拿到的「好事」不碰（收藏品回收、退费退税）；
- 让**别告诉儿女**的事，第一时间告诉儿女（#330 五板斧里的「隔离」，在老人剧本里永远存在）。

**第 4 件：管住「入口」。**
- 快递面单让老人撕掉再扔（信息是第一环的原料，见 #220）；
- 不扫码领鸡蛋、不填「免费体检登记表」、不在直播间买「专家」的任何东西；
- 大额转账设个家规：**超过 X 元，先给子女打一个电话**——不是要审批，是让骗局多一道「要过家人」的关卡，绝大多数骗局到这里就撤了。

**第 5 件：常聊，别只聊「别被骗」。**
骗子每周更新剧本，你的「叮嘱」一年才更新一次。有效的方式是聊具体案例：「最近有个直播卖保健品的被抓了，涉案一千万」——故事比道理记得牢。老人遇事第一个想起的人，是平时和他聊这些的人。

## 四、如果已经出事

- **别责备。** 受骗后老人最怕的两件事是丢脸和子女失望，瞒住不报才是最大损失来源。第一句话永远是「这不怪你，骗子是专业的」。
- **黄金半小时：** 拨打 110/96110 紧急止付，再去派出所报案，带上全部转账凭证和聊天记录（#327 有完整流程）。
- **留证据：** 保健品留实物和外包装，直播间录屏，收据全留——非法集资和养老诈骗多是集团案件，报案越早、串联越快、追赃比例越高。
- **防二次收割：** 「交钱帮你追损」「认识内部人能销案」全是第二层骗局，专骗已经报案的家庭。
